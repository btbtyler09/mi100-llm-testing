# Hardware

## MI100 chassis for the Lenovo ThinkStation P620

[`MI100_Chassis.f3d`](MI100_Chassis.f3d) is an Autodesk Fusion 360 design for a bolt-on addition to a Lenovo ThinkStation P620. It carries 4× AMD Instinct MI100 cards and a server power supply. This is the 4× MI100 setup used for the benchmarks in this repo.

Open it in Fusion 360 (File → Open → Open from my computer, or upload to a project).
